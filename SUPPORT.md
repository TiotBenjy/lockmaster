# Obtenir de l'aide

| Besoin | Où |
|---|---|
| Question d'installation, de configuration ou d'usage | Discussions GitHub du dépôt |
| Bogue reproductible | Issue « Bogue » |
| Dépôt refusé par apt, dnf ou apk | Issue « Compatibilité avec un client » |
| Idée d'évolution | Issue « Demande de fonctionnalité » |
| CVE déjà publique dans une dépendance | Issue « CVE publique dans une dépendance » |
| Vulnérabilité dans Lockmaster | **En privé uniquement** : voir `SECURITY.md` |

Avant de demander : consultez `docs/guide/` (installation, premiers pas, CI) et la commande
`lockmaster doctor`, qui diagnostique la plupart des problèmes de configuration.
